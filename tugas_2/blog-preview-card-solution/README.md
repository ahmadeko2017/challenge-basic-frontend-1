### What I learned

This challenge focused on creating a card component with hover states and a specific design system.
I implemented the "hard shadow" effect using Tailwind's `box-shadow` utility in `tailwind.config.js`:

```js
boxShadow: {
  'card': '8px 8px 0px 0px hsl(0, 0%, 7%)',
  'card-hover': '16px 16px 0px 0px hsl(0, 0%, 7%)',
}
```
